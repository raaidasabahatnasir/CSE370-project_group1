## Prerequisites
- **Node.js** (LTS recommended)
- **MySQL Server** (XAMPP or standalone)
- **Git** (optional, for cloning)

---

## Setup & Run

### 1) Start MySQL
Ensure MySQL is running on:
- **host:** `localhost`
- **user:** `root`
- **password:** *(empty)*

> The backend expects these defaults unless you change them in `Backend/config/db.js`.

### 2) Install dependencies
From the project root:

```bash
npm install
```
### 3) Run
```bash
npm start
```
